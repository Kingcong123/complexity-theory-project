Grover's Algorithm

On the previous page, we discussed how quantum computation challenges the Strong Church–Turing Thesis. We will now study one important example of a quantum algorithm that can outperform classical algorithms: Grover's algorithm. Grover's algorithm solves an unstructured search problem using substantially fewer queries than are required classically. We will first formulate the problem and construct its quantum oracle, then develop some intuition for the algorithm, and finally prove a rigorous bound on the number of queries it makes.

The Search Problem

Suppose we have a collection of \(N\) possible items, and we want to find one satisfying a certain property. For example, imagine searching through an unsorted database for an entry satisfying some condition. Without any information about how the entries are organized, a classical algorithm may have to examine a linear number of items to find the one we want.

We can formulate this problem mathematically. For simplicity, let \(N=2^n\), so that each item corresponds to a bit string \(x\in\{0,1\}^n\). Suppose we are given a Boolean function \[ f:\{0,1\}^n\to\{0,1\}, \] where \(f(x)=1\) means that \(x\) is an item we are searching for. We will assume there is exactly one such input, denoted by \(w\): \[ f(w)=1,\qquad f(x)=0\quad\text{for every }x\neq w. \] Our goal is to find this marked input \(w\).

We will treat \(f\) as an oracle, or a black box that allows us to evaluate \(f(x)\) without revealing any additional information about the function. Our main measure of complexity will be the number of oracle queries. This is important: an oracle query need not take constant time when we actually construct a circuit for \(f\). For now, we are measuring how many times an algorithm needs to use the oracle, rather than its complete running time.

The remarkable result is that Grover's algorithm finds \(w\) with high probability using only \(O(\sqrt{N})\) quantum oracle queries, whereas classical randomized algorithms require \(\Omega(N)\) queries in the worst case.

Constructing the Quantum Oracle

Why Do We Need a Reversible Oracle?

Our first task is to represent the function \(f\) using a quantum circuit. A natural idea would be to create a gate that maps \(|x\rangle\) to \(|f(x)\rangle\). However, this generally cannot be a quantum gate: it is not reversible. Many different inputs can have the same value of \(f(x)\), so knowing \(f(x)\) does not determine \(x\). Furthermore, such a map would take \(n\) input qubits to just one output qubit.

Recall from our discussion of classical reversible gates that we can preserve the input while computing a Boolean function into an extra bit. We use exactly the same construction here. Define the reversible oracle \(U_f\) by its action on computational basis states: \[ U_f|x\rangle|b\rangle =|x\rangle|b\oplus f(x)\rangle, \qquad b\in\{0,1\}. \] The first register is unchanged. The second qubit is flipped precisely when \(f(x)=1\). This is reversible because applying the transformation twice returns the original state: \[ U_f^2|x\rangle|b\rangle =|x\rangle|b\oplus f(x)\oplus f(x)\rangle =|x\rangle|b\rangle. \] Hence \(U_f\) permutes computational basis states, so it is a valid unitary transformation. As always, its action on superpositions is determined by linearity.

From a Reversible Oracle to a Phase Oracle

It turns out that Grover's algorithm is more convenient to describe using a different type of oracle. Rather than writing \(f(x)\) into an extra qubit, we want to change the sign of the amplitude associated with the marked input. Define the phase oracle \(O_f\) by \[ O_f|x\rangle=(-1)^{f(x)}|x\rangle =\begin{cases} -|x\rangle,&\text{if }x=w,\\ |x\rangle,&\text{if }x\neq w. \end{cases} \] Here, the expression \(-|w\rangle\) does not mean that \(w\) has become a different bit string. Instead, the amplitude of \(|w\rangle\) has been multiplied by \(-1\), introducing a relative phase of \(\pi\) between the marked and unmarked states.

How can we construct this phase oracle using \(U_f\)? The key is to initialize the additional qubit to the state \[ |-\rangle=\frac{|0\rangle-|1\rangle}{\sqrt{2}}. \] We have already introduced the Hadamard and T gates, so it is natural to ask whether we can prepare this state using only our elementary gate set \(H\), \(T\), and \(\mathrm{CNOT}\).

Recall that \(H|0\rangle=(|0\rangle+|1\rangle)/\sqrt{2}\), and \[ T=\begin{pmatrix}1&0\\0&e^{i\pi/4}\end{pmatrix}. \] Applying \(T\) four times gives \[ T^4=\begin{pmatrix}1&0\\0&-1\end{pmatrix}. \] Therefore, starting with an ancilla initialized to \(|0\rangle\), we can first apply \(H\) and then apply \(T\) four times: \[ T^4H|0\rangle =T^4\left(\frac{|0\rangle+|1\rangle}{\sqrt{2}}\right) =\frac{|0\rangle-|1\rangle}{\sqrt{2}} =|-\rangle. \] Thus, no additional elementary gate is required to prepare \(|-\rangle\).

Now consider passing \(|x\rangle|-\rangle\) through the reversible oracle. By linearity, \[ \begin{aligned} U_f(|x\rangle|-\rangle) &=\frac{1}{\sqrt{2}} \bigl(|x\rangle|f(x)\rangle-|x\rangle|1\oplus f(x)\rangle\bigr). \end{aligned} \] If \(f(x)=0\), this is just \(|x\rangle|-\rangle\). If \(f(x)=1\), the two terms exchange places, giving \[ \frac{|x\rangle|1\rangle-|x\rangle|0\rangle}{\sqrt{2}} =-|x\rangle|-\rangle. \] Combining the two cases, we have proved that \[ \boxed{U_f(|x\rangle|-\rangle)=(-1)^{f(x)}|x\rangle|-\rangle.} \] Notice that the extra qubit ends in exactly the same state in which it began. The only effect on the input register is the desired phase change. This phenomenon is called phase kickback. Because quantum gates act linearly, the same identity holds for every superposition of input states: \[ U_f\left(\sum_x\alpha_x|x\rangle\otimes|-\rangle\right) =\left(\sum_x(-1)^{f(x)}\alpha_x|x\rangle\right)\otimes|-\rangle. \] Thus, a single use of the reversible oracle simulates one use of the phase oracle.

In the oracle model, we assume access to \(U_f\) or \(O_f\) as a black box. If \(f\) itself can be computed efficiently by a classical circuit, we can implement its reversible version using quantum gates and auxiliary qubits, returning any temporary workspace to \(|0\rangle\) by uncomputing it. The universality of \(H\), \(T\), and \(\mathrm{CNOT}\), discussed on the previous page, allows us to express the needed reversible operations in our chosen gate set. The cost of implementing \(f\) is separate from the number of times Grover's algorithm calls it.

High-Level Intuition

Starting with a Superposition

Now that we have constructed the phase oracle, how can we use it to find \(w\)? Since there are \(N=2^n\) possible inputs, a natural starting point is to create a uniform superposition of all of them. Beginning with \(|0^n\rangle\), apply a Hadamard gate to every qubit: \[ |s\rangle=H^{\otimes n}|0^n\rangle =\frac{1}{\sqrt{N}}\sum_{x\in\{0,1\}^n}|x\rangle. \] Every possible input now has the same amplitude \(1/\sqrt{N}\). However, if we immediately measure all the qubits, the probability of observing \(w\) is still only \(1/N\). Creating a superposition by itself has not improved our chances of success.

Suppose we apply the phase oracle to this state. We get \[ O_f|s\rangle =-\frac{1}{\sqrt{N}}|w\rangle +\frac{1}{\sqrt{N}}\sum_{x\neq w}|x\rangle. \] The marked amplitude has become negative, but its magnitude has not changed. Since measurement probabilities depend on squared magnitudes, measuring immediately after this oracle query still finds \(w\) with probability \(1/N\). So, why was changing the sign useful?

The First Reflection: Marking the Correct State

The important distinction between quantum amplitudes and classical probabilities is that amplitudes can interfere. A negative amplitude may cancel with another amplitude or, after a suitable transformation, contribute to an increased amplitude elsewhere. Our phase oracle marks the correct state with a negative sign. We now need another transformation that turns this relative phase into a larger measurement probability.

Geometrically, the phase oracle is a reflection. It changes the sign of the component in the direction \(|w\rangle\) while leaving all orthogonal components unchanged. In the two-dimensional plane that will be important in our proof, this is equivalent to reflecting the state across the direction corresponding to the superposition of unmarked inputs.

The Second Reflection: Inversion About the Mean

The second transformation is called the Grover diffusion operator, denoted by \(D\). Rather than introduce any new notation, we will define it by describing exactly how it changes the amplitudes of a quantum state.

Suppose the current state is \[ |\psi\rangle=\sum_x\alpha_x|x\rangle, \] and let \(\mu\) denote the mean of its amplitudes: \[ \mu=\frac{1}{N}\sum_x\alpha_x. \] The diffusion operator is the linear transformation defined by \[ \boxed{D|\psi\rangle=\sum_x(2\mu-\alpha_x)|x\rangle.} \] In other words, \(D\) replaces every amplitude \(\alpha_x\) with \(2\mu-\alpha_x\). Each amplitude is reflected about the mean \(\mu\): an amplitude below the mean moves above it by the same amount, and vice versa. We will prove below that this operation is a unitary transformation and, geometrically, a reflection across the direction \(|s\rangle\).

Consider what happens when we apply \(D\) directly after the phase oracle. The marked amplitude is \(-1/\sqrt{N}\), while each of the \(N-1\) unmarked amplitudes is \(1/\sqrt{N}\). Their mean is \[ \mu=\frac{N-2}{N\sqrt{N}} =\frac{1-2/N}{\sqrt{N}}. \] Therefore, after the diffusion operator, the marked amplitude becomes \[ 2\mu-\left(-\frac{1}{\sqrt{N}}\right) =\frac{3-4/N}{\sqrt{N}}, \] whereas each unmarked amplitude becomes \[ 2\mu-\frac{1}{\sqrt{N}} =\frac{1-4/N}{\sqrt{N}}. \] For large \(N\), the marked amplitude has increased from approximately \(1/\sqrt{N}\) to \(3/\sqrt{N}\), while the other amplitudes have changed only slightly. We have used interference to increase the amplitude of the marked input! The overall state is still normalized, because both transformations are unitary.

Why Repeating the Two Reflections Works

What happens if we apply the phase oracle and diffusion operator again? The oracle once again reverses the marked amplitude, and the diffusion operator once again reflects all amplitudes about their new mean. For the first several iterations, this continues to increase the amplitude of the marked state. Initially, the marked amplitude is approximately \(1/\sqrt{N}\); after one iteration, it is approximately \(3/\sqrt{N}\); and after two, approximately \(5/\sqrt{N}\).

However, this increase cannot continue indefinitely, since the squared magnitudes of all amplitudes must sum to \(1\). To understand both why the algorithm makes progress and when we should stop, it helps to use a geometric picture. The entire computation takes place inside a two-dimensional plane. In this plane, the first operation reflects the state across the unmarked direction, while the second reflects it across the original uniform superposition \(|s\rangle\). The composition of two reflections is a rotation. Each pair of reflections rotates the state by a small, fixed angle toward the marked direction.

The initial state is already slightly tilted toward the marked direction. Every Grover iteration rotates it by approximately \(2/\sqrt{N}\) radians. After about \(\frac{\pi}{4}\sqrt{N}\) iterations, the state is close to \(|w\rangle\), so measuring returns \(w\) with high probability. If we continue to apply iterations beyond this point, we begin rotating past the marked direction and the probability of success decreases again. Our analysis below makes all of this exact.

The Algorithm

We can now describe Grover's algorithm using only the two transformations we have introduced. Recall that \[ O_f|x\rangle=(-1)^{f(x)}|x\rangle, \qquad D\left(\sum_x\alpha_x|x\rangle\right) =\sum_x(2\mu-\alpha_x)|x\rangle, \quad \mu=\frac1N\sum_x\alpha_x. \] One application of the oracle followed by the diffusion operator is called a Grover iteration, denoted by \[ G=DO_f. \]

Grover's Algorithm

Initialize $n$ qubits to $|0^n\rangle$.
Apply $H^{\otimes n}$ to obtain $|s\rangle=\frac{1}{\sqrt{N}}\sum_x|x\rangle$.
Apply $G=DO_f$ a total of $k$ times, where $k=\left\lfloor\frac{\pi}{4\arcsin(1/\sqrt{N})}\right\rfloor$.
Measure all $n$ qubits in the computational basis and output the observed bit string.

Rigorous Analysis

We now prove that Grover's algorithm finds the marked input with high probability after only $O(\sqrt{N})$ iterations. We will use the geometric perspective introduced in the previous section.

Reducing the Problem to Two Dimensions

Let $|w\rangle$ be the marked computational basis state. We also define $|r\rangle$ to be the equal superposition of all the unmarked states: $$ |r\rangle=\frac{1}{\sqrt{N-1}}\sum_{x\neq w}|x\rangle. $$ Both $|w\rangle$ and $|r\rangle$ have norm $1$, and they are orthogonal, since they have no nonzero amplitudes at the same positions. Hence, they span a two-dimensional plane.

Recall that the initial state is the uniform superposition of all inputs. We can rewrite it using our two new vectors: $$ |s\rangle=\frac{1}{\sqrt{N}}|w\rangle+\sqrt{\frac{N-1}{N}}|r\rangle. $$ Now define an angle $\theta$ by $$ \sin\theta=\frac{1}{\sqrt{N}},\quad \cos\theta=\sqrt{\frac{N-1}{N}}. $$ Thus, $$ \boxed{|s\rangle=\sin\theta\,|w\rangle+\cos\theta\,|r\rangle.} $$ If we draw $|r\rangle$ as the horizontal axis and $|w\rangle$ as the vertical axis, then $|s\rangle$ makes an angle of $\theta$ with the horizontal axis. Notice that $\theta=\arcsin(1/\sqrt N)$, which is approximately $1/\sqrt N$ when $N$ is large.

Why Each Iteration Is a Rotation

First, consider the phase oracle. It negates the marked state but leaves the uniform superposition of unmarked states unchanged: $$ O_f|w\rangle=-|w\rangle,\quad O_f|r\rangle=|r\rangle. $$ Therefore, the oracle reflects a vector across the $|r\rangle$-axis.

Next, take our definition of the diffusion operator. If $|\psi\rangle=\sum_x\alpha_x|x\rangle$ and $\mu=\frac1N\sum_x\alpha_x$, then $$ D|\psi\rangle=\sum_x(2\mu-\alpha_x)|x\rangle. $$ Since $|s\rangle=\frac1{\sqrt N}\sum_x|x\rangle$, we can also write $$ D|\psi\rangle=2\sqrt N\,\mu\,|s\rangle-|\psi\rangle. $$ To understand where is comes from, take $|\psi\rangle=c|s\rangle+|v\rangle$, where $c=\sqrt N\,\mu$ and $|v\rangle$ is orthogonal to $|s\rangle$. This is possible because subtracting $c|s\rangle$ leaves a state whose amplitudes sum to zero. Substituting gives $$ D|\psi\rangle=2c|s\rangle-(c|s\rangle+|v\rangle)=c|s\rangle-|v\rangle. $$ Hence, the diffusion operator leaves the component along $|s\rangle$ untouched and negates the orthogonal part. In other words, it reflects vectors across the $|s\rangle$-axis.

Both reflections keep the plane spanned by \(|w\rangle\) and \(|r\rangle\) unchanged. Suppose our current state makes an angle \(\varphi\) with the \(|r\rangle\)-axis, measured toward \(|w\rangle\). The oracle reflects this angle from \(\varphi\) to \(-\varphi\). The diffusion operator then reflects it across the direction \(|s\rangle\), which is at angle \(\theta\), changing the angle to \[ 2\theta-(-\varphi)=\varphi+2\theta. \] Thus, one complete Grover iteration rotates the state by exactly \(2\theta\) toward the marked direction.

The Probability of Success

Our initial state makes an angle of \(\theta\) with the \(|r\rangle\)-axis. Since each Grover iteration increases this angle by exactly \(2\theta\), after \(k\) iterations the angle is \[ \theta+2k\theta=(2k+1)\theta. \] Therefore, the state after \(k\) iterations is \[ \boxed{G^k|s\rangle =\sin((2k+1)\theta)|w\rangle +\cos((2k+1)\theta)|r\rangle.} \] By the Born rule, measuring this state returns \(w\) with probability \[ \boxed{\Pr[\text{measure }w]=\sin^2((2k+1)\theta).} \]

We want this probability to be close to \(1\), so we should stop when the angle \((2k+1)\theta\) is close to \(\pi/2\). This suggests \[ (2k+1)\theta\approx\frac\pi2 \qquad\Longrightarrow\qquad k\approx\frac\pi{4\theta}. \] Since we must choose an integer number of iterations, take \[ \boxed{k=\left\lfloor\frac\pi{4\theta}\right\rfloor \approx\frac\pi4\sqrt N.} \] In fact, this choice guarantees that the final angle differs from \(\pi/2\) by at most \(\theta\). To see this, the definition of the floor function gives \[ k\leq\frac\pi{4\theta}

Finally, \(\theta=\arcsin(1/\sqrt N)=\Theta(1/\sqrt N)\), so \[ \boxed{k=\Theta(\sqrt N).} \] Each iteration makes one phase-oracle query (equivalently, one call to the reversible oracle with an ancilla in \(|-\rangle\)). Therefore, Grover's algorithm needs \(\Theta(\sqrt N)\) oracle queries. This is a statement about query complexity. The total number of elementary gates also depends on how the oracle is implemented; if one oracle call costs \(S_f(n)\) gates, the full circuit uses at most \(O(\sqrt N\,(S_f(n)+\operatorname{poly}(n)))\) gates.

We assumed there was exactly one marked input. When there are \(M\) marked inputs and \(M\) is known, the same geometric idea applies with \(\sin\theta=\sqrt{M/N}\), yielding \(O(\sqrt{N/M})\) queries.

Comparison with Classical Computation

In an unstructured search problem with a unique marked input, a classical algorithm requires \(\Theta(N)\) oracle queries in the worst case, even if it is randomized and allowed a constant probability of error. Grover's algorithm reduces this to \(\Theta(\sqrt{N})\) quantum queries, giving a quadratic speedup; this is also optimal in the black-box query model. However, a quadratic speedup does not imply that \(\mathsf{BPP}\neq\mathsf{BQP}\), or that every problem has a quantum speedup. It is nevertheless a concrete example of how interference can give quantum computation a provable advantage over classical computation.
