Bits and Qubits

A Random Motivation

We will start by looking a model of computation that is more familiar: randomized computation. Take some randomized algorithm and suppose that at any point in the algorithm, the device we are using to run the algorithm can be in one of $n$ possible states, which we denote as a set of states $Q$. For simplicity, we will take $n=2$ and the states will be $0$ and $1$, so $Q = \{0,1\}$. If we don't know the state of the device, we can instead describe what we know about the state: that it is either $0$ or $1$ with some probability.
For example, if we know that the device is in the state $0$ with probability $p$ and in the state $1$ with probability $1-p$, we can write this as a probability vector in $\mathbb{R}^2$: $$ \begin{pmatrix} p \\ 1-p \end{pmatrix}.$$ We can also write operations from our current state using (left) stochastic matrices, matrices whose entries are nonnegative and columns sum to 1. For example, take the matrix $$A = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}.$$ This matrix represents the NOT gate, which flips the state of the device. Notice that $a_{0,1} = 1$ and $a_{1,0} = 1$, so the probability of moving to the state $1$ is if we start in the state $0$ is $1$ and the probability of moving to the state $0$ is if we start in the state $1$ is also $1$. Similarly, $a_{0,0} = 0$ and $a_{1,1} = 0$, so the probability of moving to the state $0$ is if we start in the state $0$ is $0$ and the probability of moving to the state $1$ is if we start in the state $1$ is also $0$.
In general, in an $n \times n$ matrix $A$, if $a_{i,j}$ denotes the probability we move to state $i$ if we start in state $j$.
Multipling the probability vector by the matrix $A$ gives us the new probability vector after applying the operation: $$ \begin{pmatrix} p \\ 1-p \end{pmatrix} \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 1-p \\ p \end{pmatrix}.$$ We will see that the quantum model of computation possesses many similar elements to this randomized model of computation.

Dirac notation

Before we introduce the quantum model of computation, we will introduce a notation for describing states.
We will use the Dirac notation to describe these states, invented by Paul Dirac. This notation will allow us to describe column vectors in a compact and elegant way. We call these objects "kets" and denote them with a vertical bar followed by the name of the state. For example, we can write the state $$0 = \begin{pmatrix} 1 \\ 0 \end{pmatrix} \quad \text{ as} \quad |0\rangle$$ and the state $$1 = \begin{pmatrix} 0 \\ 1 \end{pmatrix} \quad \text{ as} \quad |1\rangle$$. Then, we can write any vector in $\mathbb{R}^2$ as a linear combination of $|0\rangle$ and $|1\rangle$. For example, $$ \begin{pmatrix} \frac{\sqrt{2}}{2} \\ \frac{\sqrt{2}}{2} \end{pmatrix} = \frac{\sqrt{2}}{2} |0\rangle + \frac{\sqrt{2}}{2} |1\rangle.$$ We can extend this notation to represent bit strings of arbitrary length. For example, consider all possible bit strings of length two: (00, 01, 10, 11). We can associate each of these bit strings with a standard basis vector in (\mathbb{R}^4): $$ |00\rangle=\begin{pmatrix}1 \\ 0 \\ 0 \\ 0 \end{pmatrix}, \quad |01\rangle=\begin{pmatrix}0 \\ 1 \\ 0 \\ 0 \end{pmatrix}, \quad |10\rangle=\begin{pmatrix}0 \\ 0 \\ 1 \\ 0 \end{pmatrix}, \quad |11\rangle=\begin{pmatrix}0 \\ 0 \\ 0 \\ 1 \end{pmatrix}. $$ More generally, for any bit string $x\in{0,1}^n$, we define $|x\rangle$ to be the standard basis vector in $\mathbb{R}^{2^n}$ whose only nonzero entry is a $1$ in the position corresponding to $x$, where the bit strings are ordered lexicographically. For example, since $101$ is the sixth bit string of length three in lexicographic order, we have $$ |101\rangle= \begin{pmatrix} 0 \\ 0 \\ 0 \\ 0 \\ 0 \\ 1 \\ 0 \\ 0 \end{pmatrix}. $$ Therefore, the set $$ \{|x\rangle \in \{0,1\}^n\} $$ forms a basis for $\mathbb{R}^{2^n}$. In particular, every vector $$v\in\mathbb{R}^{2^n}$$ can be written as a linear combination of these vectors.

Quantum Bits

A quantum bit, or qubit, is the quantum analogue of a classical bit. Again, suppose we have some set of possible states, $Q$. Assume for sake of simplicity that $Q = \{0,1\}$. However, we no longer represent the states as a probability vector in $\mathbb{R}^2$. We maintain our representation of the states as a column vector, but we call our state a superposition of the states in $Q$. For example, $$\begin{pmatrix} \frac{\sqrt{2}}{2} \\ \frac{\sqrt{2}}{2} \end{pmatrix}, \begin{pmatrix} 0 \\ -1 \end{pmatrix}, \begin{pmatrix} \frac{-i}{2}\\ \frac{\sqrt{3}}{2} \end{pmatrix}$$ are all valid superpositions of the states in $Q$.
Notice that we no longer require the elements of the vector to be nonnegative, real, or sum to 1. Instead, we require that the Euclidean norm of the vector equal 1: $$||\vec{v}|| = \sqrt{|v_1|^2 + |v_2|^2 + \cdots + |v_n|^2} = 1.$$ Because of this change, we now refer to these elements as amplitudes instead of probabilities. More formally, we represent a qubit as a unit vector in $\mathbb{C}^2$. Using Dirac notation, we can write any qubit state as $$ |\psi\rangle=\alpha|0\rangle+\beta|1\rangle $$ where $\alpha,\beta\in\mathbb{C}$ and $|\alpha|^2+|\beta|^2=1$. As mentioned before, the amplitudes $\alpha$ and $\beta$ do not represent probabilities directly. Instead, we can obtain a probability distribution by taking their squared magnitudes. When we measure a qubit, we observe $0$ with probability $|\alpha|^2$ and $1$ with probability $|\beta|^2$. This is known as the Born rule. Intuitively, measuring a qubit means observing its state to obtain a classical bit, either $0$ or $1$. We can think of this as taking a peek at the qubit to see what the underlying state actually is, except that the result is probabilistic, and the measurement itself changes the quantum state. In particular, after measuring the qubit, its state becomes $|0\rangle$ or $|1\rangle$.

Multiple qubits

Just as we can represent a single qubit as a unit vector in $\mathbb{C}^2$, we can extend this representation to multiple qubits. For example, consider a system of two qubits. Recall that we can represent the four possible bit strings $(00,01,10,11)$ as the standard basis vectors in $\mathbb{R}^4$. Similarly, we can represent the state of two qubits as a unit vector in $\mathbb{C}^4$. Using Dirac notation, we can write any two-qubit state as $$ |\psi\rangle=\alpha_{00}|00\rangle+\alpha_{01}|01\rangle+\alpha_{10}|10\rangle+\alpha_{11}|11\rangle, $$ where each $$\alpha_{x}\in\mathbb{C}$$ and $$ |\alpha_{00}|^2+|\alpha_{01}|^2+|\alpha_{10}|^2+|\alpha_{11}|^2=1. $$ Once again, these coefficients represent amplitudes rather than probabilities. More generally, a system of $n$ qubits is represented by a unit vector in $\mathbb{C}^{2^n}$. Using Dirac notation, we can write any such state as $$ |\psi\rangle=\sum_{x\in \{0,1\}^n}\alpha_x|x\rangle,$$ where $\alpha_x\in\mathbb{C}$ for every $x\in \{0,1\}^n$, and $$ \sum_{x\in \{0,1\}^n}|\alpha_x|^2=1. $$ When we measure all $n$ qubits, the probability of observing a particular bit string $x \in \{0,1\}^n$ is $$ \Pr(x)=|\alpha_x|^2. $$ Thus, while a single qubit is described by two complex amplitudes, a system of $n$ qubits is described by $2^n$ complex amplitudes.
